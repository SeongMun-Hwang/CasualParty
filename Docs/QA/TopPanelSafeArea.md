# 전면 카메라·노치 대응

세 게임의 TopUIPanel에 SafeAreaTopPanel을 적용했다. 중앙 점수뿐 아니라 같은 줄의 타이머·순위·설정 버튼도 함께 안전 영역 안으로 이동한다. 기존 두 줄 구성과 아이콘·텍스트 간격은 유지한다.

- Screen.safeArea의 상단·좌우 경계를 캔버스 viewport 기준 앵커로 변환한다.
- 안전 영역 아래에 추가 여백 16(1080 기준 UI 좌표)을 둔다. 노치가 없는 화면에도 같은 기본 여백을 적용한다.
- 안전 영역, 캔버스 viewport, 여백이 바뀌면 위치를 다시 계산한다. 이미 적용한 이동량을 누적하지 않는다.
- 배경 전체를 축소하거나 옮기지 않으며 상단 패널만 조정한다.
- Inspector의 TopUIPanel > SafeAreaTopPanel > Top Padding에서 추가 여백을 조정할 수 있다.

자동 검증은 1080×1920 / 1080×2340 / 1440×3200 / 720×1600 해상도, 상단 제외 영역 0 / 100 / 160 / 80 픽셀, 화면 일부를 사용하는 viewport 및 초기 크기 미확정 상태를 포함한다.

실기기에서는 문제 기종의 카메라 아래로 점수가 표시되는지, 두 줄 사이 간격과 게임판 가림 여부, 타이머·순위·설정 버튼의 표시와 터치를 확인한다. 자동 검증의 가상 안전 영역 값은 특정 기종의 실제 치수를 의미하지 않는다.

검증 결과: 분리된 Unity 6000.3.10f1 프로젝트에서 회귀 테스트 26개 통과. Android 조건부 C# 컴파일 통과. 결과 파일: TopPanelSafeAreaRegressionResults.xml.
