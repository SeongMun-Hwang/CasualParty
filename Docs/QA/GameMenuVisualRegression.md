# 설정 팝업 깜빡임 수정

팝업의 배경과 SettingsCard가 클릭을 받는 Button으로 구성되어 있었고, ColorTint 전환이 켜져 있어 자식 버튼 영역에 포인터가 진입하거나 선택 상태가 변할 때 패널 표면의 밝기도 변할 수 있었다.

세 게임의 배경과 카드는 Transition=None, Navigation=None으로 바꿨다. 바깥 영역 닫기 및 카드 내부 클릭 차단은 유지한다. 음소거 아이콘 자체의 버튼 반응은 유지한다. SettingsUI가 슬라이더 표시를 갱신할 때는 SetValueWithoutNotify를 사용해 불필요한 값 변경 이벤트를 발생시키지 않는다.

Title / Restart 텍스트만 제거하고 이동·재시작 아이콘과 클릭 연결은 유지했다. 전체 상단 배치 도구로 다시 생성해도 같은 설정이 적용된다.

자동 검증은 포인터 진입 및 클릭 이벤트로 배경음·효과음·진동 버튼을 각각 두 번 조작하고, 설정값의 반전·패널 열림 유지·배경과 카드의 렌더러 색상 불변을 확인한다. 세 씬에서 불필요한 텍스트 제거도 확인한다.

검증 결과: 분리된 Unity 프로젝트에서 회귀 테스트 21개 통과. Android 조건부 C# 컴파일 통과. 결과 파일: GameMenuVisualRegressionResults.xml.
