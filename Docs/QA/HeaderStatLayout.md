# 상단 아이콘·텍스트 배치

아이콘이 텍스트의 자식이거나 서로 떨어진 좌표에 놓이던 구조를 다음처럼 통일했다. 기존 이미지와 TMP 컴포넌트를 이동하므로 점수·시간을 갱신하는 게임 코드의 참조는 유지한다.

```text
BestScoreDisplay / TimerDisplay / MineCountDisplay
  ├─ 이미지 (첫 번째 자식)
  └─ TMP 텍스트 (두 번째 자식)
```

- 컨테이너: `HorizontalLayoutGroup`. 아이콘 → 텍스트 순서, 간격 12(1080 기준 UI 좌표), 수직 가운데 정렬.
- 이미지: `LayoutElement`로 크기를 고정하고 원본 비율을 유지한다.
- 텍스트: 내용의 선호 너비를 사용하고 남는 공간을 강제로 채우지 않는다. 가용 너비가 부족하면 너비를 줄이고 TMP 자동 글자 크기 조절을 적용한다. 줄바꿈은 하지 않는다.
- 최고 기록: 컨테이너의 오른쪽 끝을 화면 우측 여백에 고정한다. 컨테이너는 오른쪽 정렬, 텍스트 자체는 왼쪽 정렬이므로 숫자가 짧아도 아이콘과 글자 사이가 벌어지지 않는다.
- 타이머: 왼쪽 영역 안에서 묶음으로 배치한다. 10SUM의 기존 배경 이미지는 바깥에 유지하고, 그 안의 `TimerDisplay`가 두 요소를 배치한다.
- 지뢰 수: 첫 줄 중앙 영역에 묶음으로 배치한다.

간격과 아이콘 크기는 각 컨테이너의 `HorizontalLayoutGroup`과 이미지의 `LayoutElement`에서 조절한다. 자식의 X 좌표로 간격을 조절하지 않는다. `ContentSizeFitter`와 매 프레임 실행되는 별도 배치 스크립트는 사용하지 않는다.

씬의 통계 표시만 다시 정리할 때는 `Tools > Casual Party > Align header icons and values`를 사용한다. 전체 상단 배치 도구에도 같은 정리 로직을 연결했다.

검증은 세 게임의 아이콘 선행 순서, 같은 부모 여부, 1·100·2147483647 값과 300·330·440 너비에서 간격 12 유지 및 영역 내 배치, 최고 기록 묶음의 우측 정렬을 포함한다. 실제 화면 크기에 따른 UI 배율은 각 씬의 기존 CanvasScaler가 적용한다.

검증 결과: Unity 6000.3.10f1 분리 프로젝트에서 기존 회귀 테스트를 포함해 20개 통과. 결과는 HeaderStatLayoutRegressionResults.xml에 저장했다.
